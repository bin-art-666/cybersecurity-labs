# 三、OpenSSL编译配置


由于系统存在多个OpenSSL版本：

- 系统默认版本：
  ```
  /usr/include
  ```

- 自己安装版本：

  ```
  /usr/local/src/openssl-4.0.1
  ```


因此gcc编译时需要指定：

```bash
gcc aes_test.c -o aes \
-I/usr/local/src/openssl-4.0.1/include \
-L/usr/local/src/openssl-4.0.1 \
-lcrypto \
-Wl,-rpath,/usr/local/src/openssl-4.0.1
```


---

## 参数解释


### -I

指定头文件路径。


例如：

```c
#include <openssl/evp.h>
```


gcc需要知道：

```
openssl/evp.h
```

在哪里。


---

### -L

指定库文件路径。


OpenSSL中的函数：

例如：

```
EVP_EncryptInit_ex()
```

实际存在于：

```
libcrypto.so
```


所以需要告诉gcc去哪里寻找。


---

### -lcrypto

链接：

```
libcrypto.so
```


其中包含：

- AES
- RSA
- SHA


等密码算法。


---

### -Wl,-rpath

指定程序运行时动态库搜索路径。


防止运行时：

```
cannot open shared object file
```

# 四、AES基本原理


## 1. 对称密码


AES属于：

```
Symmetric Cipher
```

中文：

对称密码算法。


特点：

加密密钥和解密密钥相同。


流程：

```
明文
 |
 | key
 ↓
AES加密
 |
 ↓
密文


密文
 |
 | 同一个key
 ↓
AES解密
 |
 ↓
明文
```


---

# 2. AES-256-CBC


实验采用：

```
AES-256-CBC
```


含义：


## AES

高级加密标准：

Advanced Encryption Standard


---

## 256

表示密钥长度：

```
256 bit
```

转换：

```
256 / 8 = 32 byte
```


因此：

```c
unsigned char key[32];
```


---

## CBC


Cipher Block Chaining

密码分组链接模式。


AES每次处理：

```
128 bit
```

即：

```
16 byte
```


所以：

```c
unsigned char iv[16];
```

# 五、EVP接口理解


## 什么是EVP？


EVP：

OpenSSL提供的高级密码接口。


作用：

统一调用：

- AES
- RSA
- SHA


例如：

AES：

```
EVP_EncryptInit_ex()
```


RSA：

```
EVP_PKEY_encrypt()
```


SHA：

```
EVP_DigestInit_ex()
```


---

## 为什么使用EVP？


如果直接调用底层：

AES：

```
AES_encrypt()
```


RSA：

```
RSA_public_encrypt()
```


不同算法接口不同。


EVP提供统一接口。


结构：

```
              EVP

               |

--------------------------------

AES          RSA          SHA

```

## 加密流程


```

    |

    ↓

    |

    ↓

EVP_EncryptUpdate()

加密数据


    |

    ↓

处理padding


    |

    ↓

```


---

## EVP_CIPHER_CTX


上下文结构。


保存：

```

key
IV
当前加密状态
```

```
加密任务对象
```

# 八、AES解密实现


函数：

```c
int evp_aes_cbc_decrypt()
```


流程：

```
ciphertext

      |

      ↓

EVP_DecryptInit_ex()


      |

      ↓

EVP_DecryptUpdate()


      |

      ↓

EVP_DecryptFinal_ex()


      |

      ↓

plaintext

```


---

## EVP_DecryptFinal_ex作用


主要：

1. 去除PKCS#7填充；
2. 验证填充正确性。


如果：

- key错误
- 密文被修改


可能返回失败。

# 十三、实验过程中遇到的问题


## 问题1：Segmentation fault


错误：

```
Segmentation fault
```


原因：

```c
int ciphertext_len;
```


未初始化。


导致：

```c
ciphertext_len += len;
```


使用随机值。


修改：

```c
int ciphertext_len = 0;
```


解决。


---

# 问题2：一级指针和二级指针错误


错误：

```
expected unsigned char**
but argument is unsigned char*
```


原因：

read_file函数：

错误：

```c
unsigned char **buffer
```


但是传入：

```c
unsigned char buffer[]
```


修改：

```c
unsigned char *buffer
```


解决。
