# 网络安全实验

课程实验资料归档，包含三次实验的报告、指导书与相关工具文档。

## 第一次实验：密码学基础

- `实验一 密码学实验.pdf`：实验指导书
- `AES.docx`、`RSA.docx`、`SHA256.docx`：对称加密、非对称加密与哈希算法实验
- `计算机安全实验.docx`：实验过程记录
- `实验一总结.md`：实验总结
- `1.txt`：实验用测试数据

## 第二次实验：PGP 加密

- `实验二 PGP加密实验.pdf`：实验指导书
- `实验二_PGP加密.docx`：实验报告
- `第一次实验报告.docx.gpg`：使用 PGP 加密后的报告文件
- `第一次实验报告.docx`：加密前的原始报告
- `吴文滨_0xB48070D0_public.asc`、`王贺_0x5089FA87_public.asc`：实验用公钥

## 第三次实验：漏洞检测与修复
